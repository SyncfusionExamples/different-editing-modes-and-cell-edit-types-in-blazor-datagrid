# Different Editing Modes and Cell Edit Types in Blazor DataGrid

A compact sample demonstrating how to enable and customize editing modes and cell edit types in the [Blazor DataGrid](https://www.syncfusion.com/blazor-components/blazor-datagrid). This repository contains a small Blazor WebAssembly app with examples showing inline, dialog and batch editing, and how to plug in custom cell editors.

## Overview

This sample shows how to configure the Blazor DataGrid for different editing experiences and cell edit types in a Blazor WebAssembly app. It is intended as a quick reference for trying out editing modes, custom editors, and grid behavior in a small, easy-to-run project.

## Features

- Inline, dialog and batch editing examples
- Multiple cell edit types: numeric, date, dropdown and custom component editors
- Example integration of a custom editor component via `EditTemplate`
- Minimal Blazor WebAssembly setup for quick experimentation

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/different-editing-modes-and-cell-edit-types-in-blazor-datagrid.git
cd different-editing-modes-and-cell-edit-types-in-blazor-datagrid
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
